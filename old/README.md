# old/ — archived assets (not used by the paper build)

- `original_fig1_overview.png` … `original_fig5_chloride.png` — the original
  hand-made (PowerPoint) figures from the Word manuscript, kept for reference.
  These are superseded by the code-generated figures in `figures/`.
- `budnik_map.tif`, `budnik_faultmap_modified.tif` — earlier QGIS georeferencing
  attempts of the Budnik (2010) fault map. Superseded by
  `data/clipped_budnik.tif` (the clipped, Web-Mercator version the pipeline uses).
- `budnik_faultmap.png.aux.xml` — stray QGIS sidecar.

Nothing here is referenced by `main.tex`.
